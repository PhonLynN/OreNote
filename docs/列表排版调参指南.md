# 列表排版调参指南

想改列表的观感（缩进、圆点、复选框、编号），**只看这一个文件与它指向的两个源码文件**。
改完直接编译安装，六处渲染点同时生效，不需要去别处同步。

---

## 一、改哪里

| 想调什么 | 改这个文件 | 改哪个值 |
| --- | --- | --- |
| 列表缩进多少、圆点大小/位置、复选框全部外观、编号大小 | `app/src/main/java/com/phonlynn/oreplan/core/rt/RichLayout.kt` | 见下方第二节 |
| 文字的行距松紧 | `app/src/main/java/com/phonlynn/oreplan/v2/screens/CardTextStyles.kt` | `BODY_LINE_HEIGHT_MULTIPLIER` |
| 卡片字号档（小/中/大） | `app/src/main/java/com/phonlynn/oreplan/v2/screens/BoardUi.kt` | `CardFontSizes` |

`RichLayout.kt` 里**每个常量上面都写了「改它会怎样」**，直接读那个文件也行。

## 二、`RichLayout.kt` 参数一览

排版结构：

```
容器左边
│
│←──── 缩进区（IndentEm）────→│
│                              │
│        ●                    甲乙丙丁……      ← 列表项第 1 行
│        ↑                    丁戊己庚……      ← 折行的第 2 行（自动对齐）
│        └─ 符号中心（SymbolCenterOffsetEm）
│                              ↑
│                          正文左边缘
```

| 常量 | 当前值 | 含义 | 调大 → |
| --- | --- | --- | --- |
| `IndentEm` | `1.50` | 列表整体右移量（em，1.0 = 一个中文字符宽） | 更往右 |
| `SymbolCenterOffsetEm` | `-0.75` | 符号中心相对正文左边缘的偏移（负数 = 往左） | 更靠右（0 = 压到文字上） |
| `BulletDiameterEm` | `0.26` | 圆点直径 | 圆点更大 |
| `CheckBoxSizeEm` | `0.80` | 复选框方框边长 | 方框更大 |
| `CheckBoxCornerRatio` | `0.28` | 方框圆角（占边长比例） | 更圆润 |
| `CheckBoxStrokeRatio` | `0.115` | 未勾选时的描边粗细（占边长比例） | 边框更粗 |
| `CheckBoxMinStrokeDp` | `1.1` | 描边最小宽度（dp），防止小字号下断线 | —— |
| `CheckMarkInsetRatio` | `0.24` | 对勾内缩（占边长比例） | **对勾变小** |
| `CheckMarkStrokeRatio` | `0.125` | 对勾笔画粗细 | 对勾更粗 |
| `CheckMarkP1X` … `P3Y` | 见文件 | 对勾三个折点（占可用宽度比例） | 见文件注释 |
| `OrderFontScale` | `0.94` | 有序编号字号比例 | 编号更大 |

**「符号居中于缩进区」这个约定**：`SymbolCenterOffsetEm = -IndentEm / 2`。
如果你改了 `IndentEm`，记得同步把 `SymbolCenterOffsetEm` 也改成新的 `-IndentEm / 2`，
否则符号会偏（有单测会提醒你）。

## 三、改完怎么确认没改坏

```bash
./gradlew :app:testDebugUnitTest
```

其中 `RichLayoutTuningTest` 会检查参数是否合法，例如：

- 符号偏移改成正数（会压到文字上）
- 圆点直径大于缩进区一半（会顶到正文）
- 复选框边长大于缩进区（会与上一行粘连）
- 对勾内缩 ≥ 0.5（可用宽度为负，对勾溢出方框）

这些都会在这个测试里直接报出来，并说明为什么不行。

## 四、为什么符号是自绘的

之前用字体字形（`●` / `☐` / `☑`），有两个绕不开的问题：

1. **尺寸不由我们决定**：`●` 的字形实心圆接近 0.9em，你反馈过「真的太大」；
   而且换字体就会变样。
2. **垂直位置不由我们决定**：字形自带 baseline 偏移，与文字的对齐取决于字体度量。

现在圆点、复选框、对勾全部用 `Canvas` 画（`v2/richtext/VRichSymbolLayer.kt`），
尺寸/位置/形状全部是上面那些数字，与字体无关。
