## 二、数据从哪来（没有改任何老表）

0.3.0 需要几个历史没存过的字段，全部走**扩展抽屉** `entity_ext`
（`domain/plan/PlanMeta.kt`），表结构停在 v11、`SchemaFreezeTest` 不动：

| 键 | 用途 |
| --- | --- |
| `plan.dailyMinutes` | 习惯目标的「每天目标」（设计稿「每日晨跑 30 分钟」的 30） |
| `plan.checkInTime` | 习惯的提醒时刻（`HH:mm`） |
| `plan.remindLeads` | 一个目标最多 3 档提前提醒，逗号分隔 |
| `plan.linkedEvents` | 「关联日程」的多选结果 |
| `plan.source` | 挂在 `focus_sessions` 上：这条专注是不是计时器产生的 |

其余全部复用既有列：
- 数量目标的「单位 / 目标值」= `items.unit` / `items.targetValue`；
- 习惯的「周期时限」= `items.rrule` 上的方言 `DAILY / WEEKDAYS / WEEKEND / CUSTOM:1,3,5`；
- 打卡 = `habit_logs`，数量记录 = `quantity_logs`，专注 = `focus_sessions`；
- 提醒 = `reminders`（一档一条）。

## 三、每个按钮真的做了什么（无假按钮）

### 规划首页
| 控件 | 动作 |
| --- | --- |
| 设置钮 | 打开主设置页 |
| 「开始专注」 | 进专注开始页 |
| 「查看记录」 | 进专注记录页 |
| 本周柱状图 / 周四标记 | 纯展示（数据来自 `FocusStats`） |
| 「已归档 N」 | 进已归档页 |
| 目标卡 | 打开该目标的详情弹层 |
| 空态整块 | 进新建目标页 |
| FAB `+` | 进新建目标页 |

### 目标详情弹层
分步：「推进下一步」= 勾掉第一个未完成子项（顺序解锁时校验）；点路线上的节点 = 勾选/取消那一步。
数量：「记录进度」= 打开记一笔（数量 + 备注），落 `quantity_logs`；最近记录行的垃圾桶 = 删那一条。
习惯：「今日打卡 / 取消今日打卡」= `habit_logs` 切换。
两处通用：「设置」= 进该目标的目标设置页；`×` = 关弹层。

### 新建目标 / 目标设置
| 控件 | 动作 |
| --- | --- |
| 类型三卡（仅新建可点） | 切换 `goalType`（已有目标不让改：改了历史打卡就没意义了） |
| 目标名称 | 直接可编辑 |
| 截止日期 / 周期时限 / 每天目标 / 提醒时间 | 各自打开选择弹窗，确认后写表单 |
| 子项「添加子项」 | 加一行草稿（可上下移、可删）；保存时与库里对账，**保留未变子项的完成状态** |
| 按顺序解锁 | 写 `stepOrderMode`（SEQ / FREE） |
| 开启提醒 + 提醒档位 | 一档一条 `reminders`；习惯同时维护不可见的 `HABIT_ALARM` 载体（调度器只认 RRULE） |
| 关联日程 | 多选今天起的日程，写抽屉 |
| 创建 / 保存 | 新建：建条目 + 子项；编辑：更新 + 对账子项 |
| 归档目标 / 删除目标 | 归档 = `status=CANCELLED` 并停提醒；删除 = 连子项、提醒、抽屉一起清 |

### 专注四页
| 控件 | 动作 |
| --- | --- |
| 计时方式三卡 | 倒计时 / 正计时 / 番茄钟 |
| 时长 15·25·45·60·自定义 | 写计划时长（正计时时整行置灰并给说明） |
| 对象 自由/目标/日程 | 切换选择卡的数据源；没数据时给「怎么办」的说明而不是空面板 |
| 开始专注 | 真的 `FocusController.start(...)`，然后进专注中页 |
| 结束 / 暂停 / 跳过 | 结束 = 出结果；暂停 = 停表；跳过 = 直接结束并出结果 |
| 正计时的 `+` | 补记 1 分钟（它的痛点是忘记按结束） |
| 头部 `×` | 收起（计时继续，靠悬浮窗回来） |
| 保存记录 | 写 `focus_sessions` + 抽屉来源标记 |
| 不保存返回 | 丢弃结果（强留记录反而让人不敢开始） |
| 更新进度 / 去目标填写 | 前者就地记一笔，后者跳目标详情弹层 |

### 专注记录 / 已归档
| 控件 | 动作 |
| --- | --- |
| 热力图左右拖动 | 看更早的日子（一整年 52 周，进页面时自动贴到最右 = 今天） |
| 点热力图某一格 | 选中那一天（实色方框），下方当日列表跟着换 |
| 「回到今日」 | 把选中与滚动位置一起拉回今天 |
| 日历钮 | 打开月历，选哪天看哪天 |
| 记录行 | 打开操作面板：查看关联目标 / 删除这条记录 |
| 空态整块 | 进专注开始页 |
| 筛选钮 | 状态（全部/已完成/已放弃）+ 类型（全部/分步/数量/习惯），选完立即生效 |
| 归档行 | 操作面板：恢复到进行中 / 查看目标详情 / 彻底删除（二次确认） |

### 悬浮窗
有活动专注且不在专注页时出现；可拖动（夹在可视区内）；点击回专注中页；
右上角圆点 = 计时中（accent）/ 已暂停（amber）。

## 四、口径只有一份

`domain/focus/FocusStats.kt` 是**唯一**的专注统计实现（纯函数 + 单测），
首页、记录页、目标详情三处都调它：

- 时长文案 `1h 20m` / `45m`；
- 本周 = 周一起算，与上周对比只比到「与本周同样的第几天」
  （否则周一早上永远是 −80%）；
- 连续天数：今天还没专注就从昨天数起（不能因为「今天还没做」清零）；
- 热力图：按周分列的 **52 周（一整年）**网格，五档强度（0 / <25 / <60 / <120 / ≥120 分钟）；
  可左右拖动，点格子即选中那天（实色框），「回到今日」把视图与选中拉回今天；
- 数量趋势：近 8 周的**累计值**柱 + 最后一周增量。

同理，目标进度的口径都在 `PlanUi`：分步按子项、数量按记录求和、习惯按本周打卡天数。

## 五、0.3.0 相对旧版的行为变化（用户可见）

1. **规划首页换了骨架**：旧版是「筛选胶囊 + 按类型分组的卡片网格」，
   新版是「周标题 + 今日专注卡（含本周柱状图）+ 单列目标栈」。
2. **习惯目标主色从玫红改为琥珀**（`$amber`）。依据是新设计稿：习惯卡的周条、
   类型徽章、记录页的时间轴竖条都用琥珀。玫红现在只留给危险操作。
3. **目标详情从独立页面改为页内弹层**（返回栈不再多一层）。
4. **新增专注系统**：计时（三种模式）、悬浮窗、完成页对照、热力图记录页。
   旧版只有 `focus_sessions` 表，没有任何界面。
5. **目标设置支持多档提醒**（最多 3 档，间隔 ≥30 分钟）与「每天目标」。
6. 旧版规划页的 `PlanFilter` 筛选胶囊（全部/进行中/已完成）**已移除**：
   新设计稿没有它，改由「已归档」页承担归档目标的筛选。
